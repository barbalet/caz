# Domestic Cat Stock Reference Set

Twenty open-license domestic-cat reference images from Wikimedia Commons for shaping the Caz droid toward real cat proportions and posture.

Coverage: walking, sitting, and lying poses; each includes side-on and head-on/front-facing examples. See `manifest.json` for source page, author, license, and query metadata for every file.

These are source references, not Caz assets. Preserve attribution when redistributing or deriving public design material from them.
